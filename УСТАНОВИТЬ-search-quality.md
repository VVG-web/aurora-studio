## 3. Шаг маршрута — по желанию

В `cockpit/scenarios.txt`, в конец маршрута `[fix] Починить базу`, после `kb:lint`:

```
ops:search-quality | Качество поиска числом: находит ли база сама себя | --apply
```

Тогда каждый прогон «Починить базу» будет оставлять замер в истории, и деградация
поиска станет видна сразу, а не по жалобе человека.


## Первый замер на живой базе

```bash
cd <проект> && python3 .opencode/scripts/kb_search_quality.py --sample 200 --golden --apply
```

Нужен собранный индекс (`kb:embed --apply`) и доступный шлюз эмбеддингов: вопросы
превращаются в векторы той же моделью, что и карточки.
