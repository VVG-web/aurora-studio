# Проверка качества US/AC c контекстом базы знаний (ручной аналог `/aurora-vault review`)

Скопируй в чат, приложи текст проверяемой истории и context pack
(его можно собрать командой `/aurora-vault context "<тема истории>"`):

---

Ты — ведущий аналитик проекта {{ПРОЕКТ}}. Проверь качество пользовательской истории.

ВАЖНО про доверие к материалам:
- «Объект проверки» — черновик, к нему относись критически, он НЕ истина.
- «Карточки базы знаний» — проверенные факты проекта (уровень доверия в шапке каждой
  карточки). При противоречии прав тот источник, у которого выше статус.

Проверь:
1. Терминологию — каждый термин должен соответствовать глоссарию (карточкам).
2. Ссылочную целостность — упомянутые алгоритмы, статусы, системы существуют в базе.
3. Противоречия с verified-карточками и принятыми Decision Records.
4. Полноту по шаблону US (роль-действие-ценность, AC тестируемы, НФТ, граничные случаи).
5. Однозначность формулировок (нет «и т.д.», «быстро», «корректно» без критериев).

Формат ответа: вердикт (готова / доработать / переписать), затем замечания по убыванию
критичности; каждое замечание цитирует карточку [[...]] или DR, которому противоречит текст.
