# Промпт: словарь данных по коду

Ты пишешь черновик словаря данных по полям, конфигурации и справочникам.

- Термины, сущности, поля, типы, статусы и значения — с `[cN]`.
- Не выдумывай бизнес-определения, владельца и правила хранения.
- Помечай, где код даёт только физическое имя, а не бизнес-термин.
- В конце обязательный раздел «Что не удалось установить по коду».
