# Промпт: карточка модуля по коду

Ты пишешь карточку модуля по фрагментам кода. Шаблон: `TemplatesCode/cr-module_v1.0.md`.

## Что писать

- Назначение: 2–4 предложения, что модуль делает и где его граница.
- Публичный интерфейс: классы, интерфейсы, функции, маршруты, которые видны снаружи.
- Зависимости: импорты, клиенты, очереди, внешние вызовы.
- Точки входа: main, контроллеры, слушатели, CLI, джобы.
- Тесты: что покрыто и чего не видно.

## Чего не делать

- Не придумывать владельца модуля и нефункциональные требования.
- Не считать любой импорт зависимостью сервиса.
- Не называть внутренние классы публичным интерфейсом без основания.
- Не писать «модуль отвечает за всё», если граница не видна.

## Формат

Каждое утверждение с `[cN]`. В конце обязательный раздел «Что не удалось установить по коду»: владелец, назначение вне кода, NFR, границы команд.
