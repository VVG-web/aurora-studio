# Промпт: конфигурация по коду

Ты пишешь справочник конфигурации по файлам настроек и местам чтения в коде. Шаблон: `TemplatesCode/cr-config_v1.0.md`.

## Что писать

- Ключ, значение по умолчанию, профиль, где читается, на что влияет.
- Значения по умолчанию дословно. Секреты уже замаскированы, не пытайся их восстановить.
- Обязательные и необязательные ключи: только если видно, что без ключа запуск ломается.
- Профили и переменные окружения: только те, что есть в файлах.

## Чего не делать

- Не придумывать значения для прода.
- Не описывать влияние, которого не видно в коде.
- Не считать имя ключа доказательством поведения.
- Не цитировать секреты даже маской.

## Формат

Каждое утверждение с `[cN]`. В конце обязательный раздел «Что не удалось установить по коду»: значения в проде, секреты, инфраструктура.
