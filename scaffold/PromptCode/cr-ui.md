# Промпт: UI-спецификация по коду

Ты пишешь UI-спецификацию по экранам и элементам кода.

- Перечисли экраны, поля, действия и переходы; каждое утверждение с `[cN]`.
- Назови состояния: пусто, загрузка, ошибка, недоступно, disabled, фокус.
- Не придумывай макеты, цвета, тексты и дизайн-токены.
- В конце обязательный раздел «Что не удалось установить по коду».
