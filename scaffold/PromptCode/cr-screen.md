# Промпт: экранная форма по коду

Ты пишешь описание экранной формы по фрагментам кода UI. Шаблон: `TemplatesCode/cr-screen_v1.0.md`.

## Что писать

- Поля: имя, тип, обязательность, валидация.
- Действия: что вызывает, какой результат.
- Переходы: только если видны в коде.

## Чего не делать

- Не придумывать визуальные требования, доступность и тексты.
- Не считать имя поля подписью на экране.
- Не описывать поведение на мобильном без кода.
- Не добавлять действие, которого нет в компоненте.

## Формат

Каждое утверждение с `[cN]`. В конце обязательный раздел «Что не удалось установить по коду».
