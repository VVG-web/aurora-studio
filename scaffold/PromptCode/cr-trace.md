# Промпт: матрица трассировки по коду

Ты пишешь черновик матрицы трассировки по тестам и проверкам.

- Связывай тест, критерий и координату кода; каждое утверждение с `[cN]`.
- Явно назови пробелы: что не связано ни с критерием, ни с тестом.
- Не придумывай ID требований и номера US/UC/AC.
- В конце обязательный раздел «Что не удалось установить по коду».
