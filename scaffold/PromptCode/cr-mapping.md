# Промпт: маппинг данных по коду

Ты пишешь маппинг полей по фрагментам кода. Шаблон: `TemplatesCode/cr-mapping_v1.0.md`.

## Что писать

- Источник, поле источника, приёмник, поле приёмника, преобразование.
- Переименования, приведение типов, вычисления, значения по умолчанию.

## Чего не делать

- Не придумывать маппинг на стороне внешней системы.
- Не считать совпадение имён автоматическим маппингом.
- Не описывать преобразование, которого нет в коде.
- Не добавлять поле, которого нет в DTO или сущности.

## Формат

Каждое утверждение с `[cN]`. В конце обязательный раздел «Что не удалось установить по коду».
