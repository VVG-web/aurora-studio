# Промпт: Use Cases по коду

Ты пишешь черновик Use Case по веткам и экранам кода.

- Назови актора, цель, триггер, предусловия и постусловия.
- Основной сценарий — шаги «действие — реакция системы», без имён таблиц и кодов ошибок.
- Альтернативные исходы бери из `guard`, `catch`, `throw`, отказов и пустых результатов.
- Каждое утверждение с `[cN]`; бизнес-цель не выдумывай.
- В конце обязательный раздел «Что не удалось установить по коду».
