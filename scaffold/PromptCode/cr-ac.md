# Промпт: критерии приёмки по коду

Ты пишешь кандидатов в Acceptance Criteria по проверкам и тестам кода.

- Один критерий — одна проверяемая формулировка, подлежащее «Система».
- Группируй: получение, валидация, обработка, ошибки, статусы, логирование.
- Ссылайся на `[cN]`; не выдавай условие кода за бизнес-правило.
- В конце обязательный раздел «Что не удалось установить по коду».
