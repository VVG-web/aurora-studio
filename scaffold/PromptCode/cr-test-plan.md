# Промпт: план тестирования по коду

Ты пишешь черновик плана тестирования по существующим тестам и проверкам.

- Тесты, что они покрывают и где пробелы — с `[cN]`.
- Назови данные, окружения и разрешения, которых не хватает.
- Не выдавай существующие тесты за полный план приёмки.
- В конце обязательный раздел «Что не удалось установить по коду».
