# Промпт: карта тестов по коду

Ты пишешь карту тестов по фрагментам кода. Шаблон: `TemplatesCode/cr-tests_v1.0.md`.

## Что писать

- Тест, что проверяет, какой класс или сценарий является целью.
- Покрытие по областям: есть тест, чего не видно.
- Пробелы: области без тестов и тесты, которые проверяют не то.

## Чего не делать

- Не считать отсутствие теста отсутствием реализации.
- Не придумывать тест, которого нет в коде.
- Не называть тест доказательством выполнения требования.
- Не выводить цель теста только из имени.

## Формат

Каждое утверждение с `[cN]`. В конце обязательный раздел «Что не удалось установить по коду»: тесты вне репозитория, CI, ручные проверки, тестовые среды.
