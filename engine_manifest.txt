# Aurora Studio — engine manifest.
# Белый список инженерных файлов, которыми управляет kit. `aurora.py update`
# перезаписывает В ПРОЕКТЕ только эти пути. Всё остальное (config, знания, Raw,
# Sources, Deliverables, Artifacts, Workspaces, Templates/, Prompts/) не трогается.
#
# Формат строки:  <путь-в-kit>  =>  <путь-в-проекте>
# Спец-правила (в скобках после →) обрабатываются update-скриптом:
#   (connectors) — модули источников: манифест каждого кладётся в .opencode/connectors/,
#              скрипт запуска — в .opencode/scripts/, а тело sync-скилла размножается
#              по существующим папкам скиллов проекта с сохранением slug в имени.
#              Тело НЕ перезаписывается (проект дорабатывает его под свой контур) —
#              новая версия ложится рядом как <файл>.new
#   (agents) — регенерировать из шаблона, подставив имя/slug/ключи из aurora.config.yaml
#   (seed)   — вариант (1): не перезаписывать; новую версию положить рядом как <файл>.new
