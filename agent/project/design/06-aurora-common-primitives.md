# Aurora Common Primitives Design

## Overview

`scripts/aurora_common.py` (540 строк, только стандартная библиотека) — единственная
реализация того, что нужно каждому скрипту движка: парсер frontmatter, регулярка
wiki-ссылок, карта гомоглифов, постоянные статусов и доверия, границы имён карточек,
запись полей, обход базы, git-стражи и чтение конфига. До этого модуля парсер
frontmatter жил в восьми скриптах, регулярка wiki-ссылок — в восьми, карта гомоглифов —
в двух: любая правка требовалась восемь раз, и однажды кто-то бы забыл.

Модуль лежит рядом со скриптами (в ките `scripts/`, в проекте — `.opencode/scripts/`),
поэтому обычный `import aurora_common` работает без настройки путей: Python кладёт
папку запускаемого скрипта первой в `sys.path`. Внешних зависимостей нет — ядро кита
остаётся устанавливаемым чистым Python 3.

## Architecture / Components

### Словарь карточек и статусы
**File:** scripts/aurora_common.py
**Purpose:** единый источник правды о том, что такое карточка и что считается знанием.
**API / Interface:**
```python
KB_ROOT = "AuroraKnowledgeDB"
SERVICE_STATUS = "index"
STATUSES = ("knowledge", "draft", "deprecated", SERVICE_STATUS)
KNOWLEDGE = ("knowledge",)
TRUSTED = ("knowledge", "verified", "canonical")
RETIRED_FIELDS = ("audience", "confirmed_by")
RETIRED_STATUS = {"canonical": "verified"}
```
`STATUSES` — шкала после перехода на вычисляемое доверие: `knowledge` (знание из
доверенного источника) и `draft` (из недоверенного или недоказанного) — прежние
`imported`/`in-review`/`verified` означали ступени ручной приёмки, которой больше нет:
доверие считает движок по статусам задач, а не человек. `SERVICE_STATUS` (`index`) —
файл, собранный командой (карта содержания, оглавление): не знание и не черновик,
доверие к нему не применяется вовсе.

`TRUSTED` — что код считает знанием: новая шкала плюс `verified` и `canonical`, которые
читаются как знание *пока* проект не прошёл пересборку — база, обновившая движок, не
должна ослепнуть до `kb:trust`. `canonical` убран из схемы в 1.10.0 и читается как
синоним `verified` (маппинг `RETIRED_STATUS`). `RETIRED_FIELDS` — поля, снятые вместе с
прежней приёмкой и убираемые на старых базах; `trust` в этот список входить **не
может**: с 1.92 его пишет `kb:trust` как класс источника, посчитанный по статусам задач,
и старый список стирал бы то, что движок только что записал.

### Граница «документ / производство»
**File:** scripts/aurora_common.py
**Purpose:** где тело артефакта заканчивается и начинаются разделы производства
(уточнения, допущения, замечания критика, находки Момуса, план) — то, что заказчику не
уезжает. Граница — маркер **отдельной строкой**, а не подстрокой:
```python
MADE_MARK = "<!-- ниже — производство, в чистовик не идёт -->"

def clean_copy(text: str) -> str:
    lines = text.splitlines(True)
    for i, line in enumerate(lines):
        if line.rstrip("\r\n") == MADE_MARK:
            return "".join(lines[:i]).rstrip() + "\n"
    return text
```
Точное совпадение строки, без `strip()`: маркер внутри блока кода (артефакт про саму
Аврору) не режет документ, а движок пишет маркер от начала строки. Используют
`make_kinds.py`, публикация (`ship:publish`) и выгрузка.

### Имена карточек
**File:** scripts/aurora_common.py
**Purpose:** канонические ключи сравнения и переименования, чтобы ссылка и файл
сошлись из одного заголовка.
**API / Interface:**
```python
LAT2CYR = {"A": "А", "B": "В", "C": "С", "E": "Е", "H": "Н", "K": "К", "M": "М",
           "O": "О", "P": "Р", "T": "Т", "X": "Х", "Y": "У",
           "a": "а", "c": "с", "e": "е", "o": "о", "p": "р", "x": "х", "y": "у"}
CYR2LAT = {v: k for k, v in LAT2CYR.items()}
SERVICE_NAMES = {"index.md", "_index.md", "manifest.json", "README.md"}
KNOWN_EXT = (".md", ".png", ".jpg", ".jpeg", ".svg", ".pdf", ".drawio", ".xml", ".mmd",
             ".puml", ".json", ".txt", ".docx", ".xlsx", ".pptx", ".csv")
```
- `fold(name)` — гомоглифы → латиница, нижний регистр: ключ сравнения имён.
- `fold_hard(name)` — то же без разделителей: «ALG-014. Подготовка» ==
  «ALG-014-Подготовка»; ссылка на такое имя не битая, а набранная иначе.
- `fix_mixed_script(name)` — чинит буквенные группы со смешанной кириллицей/латиницей по
  «уликам» (буквы, есть только в одном алфавите): «АLG» → «ALG», «AИС» → «АИС». Уликов
  нет или они противоречат — группа не трогается: движок не угадывает.
- `card_filename(title)` — заголовок → имя файла по одному правилу на всех (кавычки
  и скобки в дефисы, `№` → `No`, сжатие `--`).
- `card_stem(name)` — имя карточки из ссылки или пути, режет **только известное
  расширение** (`.md`/`.markdown`/`.mdx`), а не всё после последней точки: точки — часть
  кода (`US-3.6.2`, `ALG-3.21`, `AC-4.2.19`), и `os.path.splitext` обрезал бы ссылку
  `us-3.6.2-nachisleniya` до `us-3.6` — живая карта, объявленная «без связей».
- `is_service(path)` — служебный файл (`SERVICE_NAMES`, имена с `_`, `/meta/`,
  `/_meta/`): не карточка знаний.

### Ссылки
**File:** scripts/aurora_common.py
**Purpose:** читать и переписывать `[[цель#якорь|подпись]]` (с `!` для встраивания)
без потери якорей, подписей и экранирования.
**API / Interface:**
```python
LINK_RE = re.compile(r"(!?)\[\[([^\]|#]+?)((?:#[^\]|]*)?)(?:(\\?)\|([^\]]*))?\]\]")
RELATED_MD = re.compile(r'^\s*-\s*"?\[([^\]]+)\]\([^)]*\)"?\s*$', re.M)
```
Вертикальная черта внутри таблицы markdown экранируется — `[[Имя\|подпись]]` — и
регулярка принимает и эту форму: без неё целью ссылки становилось «Имя\» с хвостовым
бэкслэшем, и оглавления (это таблицы — там ссылок больше всего) не сходились ни с
какой карточкой. Функции:
- `leaf_name(target)` — имя цели без пути, якоря и **настоящего** расширения
  (`KNOWN_EXT`); «Спецификация 1.2» — не расширение.
- `link_targets(text)` — имена целей всех wiki-ссылок; `link_refs(text)` — цели «как
  написано», с путями и якорями.
- `related_targets(text)` — имена из блока `related:`, который пишется
  markdown-ссылками, не wiki: граф связей (`kb:links --cards`) складывает связи как
  `[Имя](Имя.md)`, и `link_targets` их не видит. На живом проекте это стоило правилу
  доверия по связям всей работы: связей в базе 2386, а правило видело 4.
- `rewrite_links(text, mapping)` — переписать цели по карте, сохраняя якоря, подписи и
  экранирование черты (потеряй его — развалится ячейка таблицы).

### Frontmatter: чтение и запись
**File:** scripts/aurora_common.py
**Purpose:** один разбор и одна запись полей шапки на всех скриптах.
**API / Interface:**
```python
def split_frontmatter(text: str):
    """→ (head, rest) без разделителей, либо (None, None), если шапки нет."""

def with_fields(text: str, fields: dict) -> str:
    """Проставить поля в шапке карточки, вернув файл целиком. Тело не меняется."""
```
- `frontmatter(text)` — плоские поля шапки (значения очищены от кавычек);
  `aliases(text)` — inline-список и блочный, повтор синонима внутри карточки — мусор
  извлечения, а не конфликт, поэтому дедупликация.
- `body(text)` — тело без шапки; `set_field(head, key, value)` — поле в шапке **без
  разделителей**.
- `with_fields` — единственный правильный способ записать поле. «Почти так» дважды
  стоило дорого: поле уехало в первую строку тела 2033 карточкам, тезис — внутрь
  раздела «Источник». Проверка идёт при каждой записи в любом проекте: тело обязано
  остаться прежним, поле — оказаться в шапке; не сошлось — `AssertionError` и испорченный
  текст никому не отдаётся.
- `as_list(value)` — `based_on: ["[[A]]", "[[B]]"]` → `['A', 'B']`.

### Карточка и обход базы
**File:** scripts/aurora_common.py
**Purpose:** одна модель «карточки» и один обход для всех, кто читает базу целиком.
**API / Interface:**
```python
class Card:
    """Карточка базы: путь, имя, шапка, тело, раздел."""
    def __init__(self, path: str, text: str, root: str = KB_ROOT): ...
    @property
    def status(self) -> str: ...      # fm: status
    @property
    def source(self) -> str: ...      # fm: source
    @property
    def is_stub(self) -> bool: ...    # «заготовка» в тегах / «_Заготовка:» в теле
    def links(self) -> list: ...

def load_cards(root: str = KB_ROOT, skip_service: bool = True,
               skip_archive: bool = True) -> dict: ...   # {путь: Card}
def walk_md(root: str, skip_service: bool = False, skip_archive: bool = False): ...
def inbound_counts(root: str) -> dict: ...   # {имя: сколько на неё ссылок из базы}
def card_body(text: str) -> str: ...
def body_hash(body: str) -> str: ...         # md5, 12 символов
```
Раньше у `ctx_pack` и `kb_fix` были свои классы с одинаковой шапкой, а `kb_queue` и
`aurora_stats` собирали то же самое словарями — четыре способа назвать одно и то же.
`inbound_counts` считает по **всем** файлам, включая навигационные (`_index.md`, MOC):
присутствие в индексе — тоже связность, иначе «сиротами» станет вся база. `body_hash` —
отпечаток без шапки и с обрезанными хвостовыми пробелами: приёмка относится к
конкретному тексту, а не к имени файла, и линтер сверяет тот же отпечаток.

### Обвязка: git, окружение, конфиг
**File:** scripts/aurora_common.py
**Purpose:** мелкая механика, одинаковая во всех массовых скриптах.
**API / Interface:**
```python
def git_dirty(path: str = ".") -> list: ...
def git_guard(path: str, allow_dirty: bool, what: str = "операция") -> bool: ...
def child_env(**extra) -> dict: ...
def config_value(key: str, default: str = "") -> str: ...
def config_list(key: str) -> list: ...
```
- `git_guard` — массовая запись по грязному дереву делает откат невозможным: скрипт
  отказывается писать, если не `--allow-dirty`, и подсказывает `git add -A && git
  commit -m 'WIP'`.
- `child_env` — окружение для дочернего процесса без чужих `Malloc*`: macOS печатает в
  stderr «MallocStackLogging: can't turn off…» каждому процессу с отладочной
  переменной, и чужое сообщение врезается в строку прогресса движка.
- `config_value` / `config_list` — простейшие поля и списки из `aurora.config.yaml`
  без PyYAML: списков в конфиге четыре вида, и до 1.44.0 каждый скрипт разбирал их
  своим regex.

## Design Decisions

- **Одна реализация, импорт, а не копия.** Модуль лежит рядом со скриптами, обычный
  `import` работает без путей, правка делается один раз.
- **Доверие — конвенция чтения, а не записанное поле.** `TRUSTED` намеренно охватывает
  новую и прежнюю шкалы, чтобы обновлённая база не ослепла до пересборки — тот же
  принцип «не терять доверие на переходе», что и `RETIRED_STATUS`.
- **Запись полей защищена проверкой, а не договорённостью.** `with_fields` при каждом
  вызове сверяет, что тело не тронуто и поле встало в шапку: повреждение расходится по
  базе одним прогоном, а замечают недели спустя — дешевле любого разбора последствий.
- **Граница — точная строка, а не подстрока.** Маркер производства в блоке кода не
  обрывает документ; маркер с отступом не считается маркером, потому что движок пишет
  его от начала строки.
- **Имя режется по известным расширениям.** Точки — часть кода карточек, и
  «расширение» — это только `KNOWN_EXT`; иначе ссылки на `US-3.6.x` не сходятся ни с
  чем.
- **Смешанное письмо чинится по уликам, а не угадыванием.** Без однозначных улик группа
  не трогается: ложное переименование дороже, чем оставленное как есть.
- **stdlib только.** Ни одной внешней зависимости: скрипты запускаются с чистой
  установкой Python, а конфиг читается регулярками вместо PyYAML.
