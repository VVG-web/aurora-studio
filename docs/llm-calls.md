# Вызовы моделей

Где Аврора зовёт модели: когда, какие роли по шагам, какой промпт, какие инструменты доступны модели и идёт ли вызов через Pydantic AI. Страница собрана из каталога `scripts/llm_calls.json` (`python3 scripts/llm_calls.py --write`); тесты сверяют каталог с кодом, так что новое место вызова без описания здесь роняет проверку.

**Роль — это цепочка моделей.** Какие модели стоят за ролью, задаёт раздел «Модели» панели (`local/models.json` кита, одна настройка на все проекты). Первая модель цепочки отвечает, следующие — запасные: шлюз не ответил или перегружен — вызов идёт дальше. Там же — рассуждения роли (галочка «рассуждения» у роли на вкладке LLM). Живые цепочки по каждому вызову — «Модели → Где работают».

<a id="build"></a>

## Разбор источников на карточки

- **Когда.** Команда agent:build — партиями, пока план не разобран; расписание Cron.
- **Команды:** `agent:build`.
- **Маршруты:** «Обновить базу», «Пересобрать базу с нуля».

| Роль | Что делает | Промпт |
|---|---|---|
| Планировщик (planner) | Большой источник без разметки: план разделов, по которым его резать. | `PROMPT_PLAN_SOURCE` (agent_runner.py) |
| Планировщик (planner) | Стенограмма встречи из Raw/meetings: план по частям. | `PROMPT_MEETING` (agent_runner.py) |
| Писатель (worker) | Раскадровка источника: границы тем, имена карточек, вид знания. Текст в карточки переносит движок, а не модель. | `PROMPT_BUILD` (agent_runner.py) |
| Писатель (worker) | Источник без структуры: разбирать, пропустить или считать служебным. | `PROMPT_NO_SECTIONS` (agent_runner.py) |
| Критик (critic) | Проверка раскадровки до записи в базу. | `PROMPT_BUILD_CRITIC` (agent_runner.py) |
| Критик (critic) | Проверка решения по источнику без структуры. | `PROMPT_NO_SECTIONS` (agent_runner.py) |

- **Инструменты:** нет: всё нужное движок кладёт в задание.
- **Путь:** Pydantic AI.
- **Потом:** Движок переносит текст, ставит отметку о разборе, линтер проверяет карточки.

<a id="distill"></a>

## Тезисы карточек

- **Когда.** Команда agent:distill; `--recheck` — повторная проверка тезисов без опоры.
- **Команды:** `agent:distill`.
- **Маршруты:** «Обновить базу», «Починить базу», «Пересобрать базу с нуля».

| Роль | Что делает | Промпт |
|---|---|---|
| Писатель (worker) | Тезис карточки из перенесённого текста источника. Источник изменился — PROMPT_REDISTILL; длинный текст — по частям (PROMPT_DISTILL_PART) и сборка (PROMPT_DISTILL_JOIN). | `PROMPT_DISTILL` (agent_runner.py) |
| Планировщик (planner) | Разросшаяся карточка: план разделения на несколько. | `PROMPT_PLAN_SPLIT` (agent_runner.py) |
| Писатель (worker) | Абзацы, повторяющиеся на десятках страниц: шаблон это или знание. | `PROMPT_TEMPLATE_KINDS` (agent_runner.py) |
| Момус (qa) | Момус: каждое утверждение тезиса опирается на источник. Без опоры — пометка и повторная проверка. | `PROMPT_MOMUS` (agent_runner.py) |

- **Инструменты:** нет.
- **Путь:** Pydantic AI.
- **Потом:** Тезис без опоры не становится знанием; доверие считает движок.

<a id="ask"></a>

## Спросить базу

- **Когда.** Раздел «Спросить», команда agent:ask. Модель выбирается в разделе: роль (по умолчанию «Писатель») или ровно модель провайдера.
- **Команды:** `agent:ask`.
- **Маршруты:** «Написать артефакт».

| Роль | Что делает | Промпт |
|---|---|---|
| Писатель (worker) — выбирается | Ответ только по паку карточек, со ссылкой на каждое утверждение; уточняющий вопрос продолжает разговор. | `PROMPT_ASK` (agent_runner.py) |
| Момус (qa) | Момус проверяет, что ответ опирается на карточки пака. | `PROMPT_MOMUS` (agent_runner.py) |

- **Инструменты:** нет: пак знаний собирает движок гибридным поиском (слова и смысл).
- **Путь:** Pydantic AI.
- **Потом:** Движок разбирает ссылки ответа по базе; разговор пишется в meta/ask/.

## Артефакт (Продуктивность)

- **Когда.** Раздел «Продуктивность», команда agent:make.
- **Команды:** `agent:make`.

| Роль | Что делает | Промпт |
|---|---|---|
| Планировщик (planner) — с инструментами | Расспрос и план документа. Единственный шаг с инструментами: может доискать в базе и в MCP, выбранных в запросе. | `PROMPT_MAKE_PLAN` (agent_runner.py) |
| Писатель (worker) | Документ по плану и форме вида. | `PROMPT_MAKE_WRITE` (agent_runner.py) |
| Критик (critic) | Проверка соответствия форме и плану. | `PROMPT_MAKE_CRITIC` (agent_runner.py) |
| Момус (qa) | Момус: утверждения документа опираются на пак. | `PROMPT_MOMUS` (agent_runner.py) |

- **Инструменты:** у планировщика: read_file, list_dir, kb_search, kb_context, artifact_spec и MCP запроса; сторож исходящего пропускает наружу только слова задания и пака.
- **Путь:** Pydantic AI.

<a id="bot"></a>

## Бот проекта

- **Когда.** Раздел «Боты» → «Запустить», расписание бота, шаг «бот» цепочки Cron, команда bot:run.
- **Команды:** `bot:run`.

| Роль | Что делает | Промпт |
|---|---|---|
| Планировщик (planner) — без рассуждений | До работы: понятия, термины и коды из задания и ссылок — для пака знаний (контекст проекта). Без рассуждений. | `PROMPT` (bot_context.py) |
| Писатель (worker) — выбирается, с инструментами | Промпт бота с паком знаний. Роль или ровно модель — в карточке «Модель» бота. | `bots/*.md` |

- **Инструменты:** read_file, list_dir, kb_search, kb_context, artifact_spec, save_output и MCP бота (сервер aurora — ревью, Jira, Confluence, память, замок, время); не больше 40 вызовов.
- **Путь:** Pydantic AI.
- **Потом:** Прогон без вызова инструментов при своих MCP — неудача с причиной.
