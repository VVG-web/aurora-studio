# Покрытие страниц Confluence (внутренний документ проекта)

Этот файл сопоставлял страницы конкретного пространства Confluence с файлами kit'а.
Он относится не к фреймворку, а к внедрению в одном контуре, поэтому из поставки
убран: адреса и номера страниц у каждой команды свои.

Если нужно вести такое сопоставление у себя — заведите его в проекте, а не в ките:
`Workspaces/внедрение/confluence-coverage.md`.
