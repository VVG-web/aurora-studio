# Разделы панели

Раздел панели — папка. Положили её сюда, и в меню появился пункт: ни сервер, ни разметку
панели править не нужно — тем же приёмом, каким появляется скин.

```
cockpit/modules/<id>/
  module.json      имя, группа меню, порядок, что разделу нужно
  view.html        разметка раздела (без <section> — его заводит ядро)
  view.js          модуль ES: mount(ctx) и refresh(ctx)
  i18n/ru.json     строки раздела, ключи начинаются с <id>.
  i18n/en.json     перевод
```

## Манифест

```json
{
  "id": "reports",
  "name": { "ru": "Отчёты", "en": "Reports" },
  "about": { "ru": "Готовые дашборды по проекту.", "en": "Ready-made dashboards." },
  "group": "project",
  "order": 80,
  "needs": ["project"],
  "commands": ["ops:report"],
  "for": "1.124.0"
}
```

| Поле | Что значит |
|---|---|
| `id` | имя папки; расходится с ней — раздел не поднимется, и панель скажет почему |
| `name` | подпись в меню на каждом языке; языка нет — берётся русская |
| `group` | `machine`, `project` или `engine` — три группы меню |
| `order` | место внутри группы; у встроенных разделов те же числа в `data-order` |
| `needs` | `project` — без выбранного проекта раздел не открывается, панель уводит на Мостик |
| `commands` | какие команды движка раздел зовёт: по реестру видно, кто чем пользуется |
| `for` | версия ядра, под которую раздел собран; отстал — панель предупредит в консоли |
| `dev` | `true` — раздел в разработке: в меню его нет, пока не открыта «Разработка» (семь нажатий на «О проекте»), и по адресу страницы в него не попасть |

## Жизнь раздела

Разметка и скрипт приезжают **по требованию**: раздел, в который не заходили, не стоит
ни одного запроса. Дальше ядро зовёт две точки входа:

```js
export function mount(ctx){ /* один раз: подписки, обработчики */ }
export async function refresh(ctx){ /* каждый раз при открытии раздела */ }
export default { mount, refresh };
```

## Что даёт `ctx`

Список короткий намеренно: чем шире вход, тем сильнее раздел прирастает к панели и тем
меньше смысла в самой папке. Нужного нет — заводится поле здесь, а не дотягивание до
`window`: тогда об этом знает ядро, а не только автор раздела.

| Поле | Что это |
|---|---|
| `t(key, vars)` | строка из каталога; ключа нет в переводе — придёт русская |
| `el`, `$`, `$$` | сборка узлов и поиск **внутри своего раздела**, в чужой не заглянуть |
| `api(path, opts)` | запрос к серверу панели, токен подставляется сам |
| `toast(msg, kind)` | сообщение человеку |
| `run(cmd, args)` | запуск команды без экрана |
| `runWatched(cmd, args)` | запуск, за которым человек смотрит в консоли |
| `openRun(cmd, flags)` | окно запуска с модификаторами и подтверждением |
| `openDoc(path)` | открыть документ в справке |
| `openPath(path)` | открыть файл проекта в редакторе |
| `busyElsewhere(cmd)` | проверка, не идёт ли уже такая работа |
| `reloadHealth()` | пересчитать здоровье проекта (обновит и отметки в меню) |
| `restartPanel()` | перезапустить панель и перечитать страницу, когда новый процесс ответит |
| `show(view, payload)` | перейти в другой раздел, при желании с грузом |
| `isEngineCmd(row)` | команда движка, а не аналитика: её место в «Разработке» |
| `runs.last(cmd)`, `runs.mark(rc)` | журнал запусков и трактовка кода возврата |
| `ui.metric`, `ui.metricCard` | плитки метрик — одни на всю панель |
| `ui.kindChip(kind)` | чип исполнителя команды: скрипт, модель или оба |
| `ui.goRoute(id, label)`, `ui.goCmd(cmd, args, label)` | переход «починить это» с плитки |
| `aura(project)` | цвет проекта и причина: тот же ответ, что на Мостике |
| `fmt` | `ago`, `kb`, `when`, `esc`, `tick`, `md` — единые формат и экранирование |
| `project`, `state`, `health`, `lang` | выбранный проект, машина, здоровье, язык |
| `token` | токен сессии для ссылок `href` на файлы панели |
| `id`, `root` | имя раздела и его узел в разметке |

Груз перехода (`show("reference", {doc: "CHANGELOG.md"})`) приезжает во второй аргумент
`refresh(ctx, payload)`. Так один раздел просит другой показать конкретное — не зная о
нём ничего, кроме имени.

## Строки

Ни одной русской строки в коде раздела: всё через `t()` и `data-i18n`. Ключи начинаются
с имени модуля (`reports.title`) — иначе два раздела однажды заведут одинаковый ключ и
начнут перекрашивать надписи друг другу. Полнота проверяется командой:

```bash
python3 scripts/kit_i18n.py --check
```

Она же заводит новый язык сразу во всех каталогах: `--new de "Deutsch"`.

## Границы

- Раздел не правит чужую разметку и не лезет в `document` мимо `ctx`.
- Раздел не считает ничего сам: числа приходят от команд движка, как и во всей панели.
- Оформление — не дело раздела: цвета, отступы и формы берутся токенами
  (`cockpit/skins/README.md`), свой цвет в разметке раздела — ошибка.
- Секреты раздел не показывает и не принимает: про токены синка панель знает только
  «заполнено» или «пусто».
