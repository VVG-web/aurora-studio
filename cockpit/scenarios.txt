# Быстрый старт — маршруты рутинной работы.
#
# Маршрут проходится одной кнопкой: панель выполняет шаги по порядку и останавливается,
# только если команда не отработала (код 2 и выше). Код 1 — «отработала и нашла, что
# чинить» — маршрут не останавливает, это нормальное состояние живой базы.
#
# Формат:
#   [id] Название маршрута | когда его проходят
#   команда | зачем этот шаг | флаги (необязательно)
#   - произвольный текст | что делает человек | что сказать ассистенту (необязательно)
#
# Флаги пишутся так, как маршрут должен пройти начисто: с `--apply` там, где шаг обязан
# записать результат. Кнопка «Посмотреть» снимает `--apply` со всех шагов и показывает
# тот же маршрут без записи.
#
# `--allow-dirty` у пишущих шагов не прихоть: после первого же шага дерево перестаёт быть
# чистым, и без него маршрут остановился бы на втором. Откат при этом не теряется —
# зафиксируйте свою работу до маршрута, и `git reset --hard` вернёт всё, что он сделал.
#
# Шаг-человек (строка с «-») панель не запускает: это работа, которую машина не делает.
# Таких шагов осталось мало — то, что раньше уходило в чужой чат, теперь делает
# встроенный агент командами `agent:*`.
#
# Файл лежит в ките и правится как обычный текст: добавили строку — появился шаг.
