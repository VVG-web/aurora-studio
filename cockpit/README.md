# Aurora Cockpit

Локальная панель управления Авророй: все проекты машины, здоровье баз, запуск команд и маршрутов,
редактор файлов, граф знаний, вопросы к базе, установка недостающего, обновление движка и справка —
в одном окне. Полное описание — [docs/control-panel-ui-requirements.md](../docs/control-panel-ui-requirements.md)
(English: [docs/en/control-panel.md](../docs/en/control-panel.md)).

```bash
python3 aurora.py cockpit
```

Откроется браузер на `http://127.0.0.1:8787/?t=<токен>`.

**Где панель ищет проекты.** Кит и проекты не обязаны лежать рядом. Список папок правится в панели
(«Настройка кита» → «Где панель ищет проекты») и хранится в `~/.aurora/cockpit-roots.txt`; при первом
запуске туда попадает папка рядом с китом.

```bash
python3 cockpit/aurora_cockpit.py --port 9000            # порт
python3 cockpit/aurora_cockpit.py --add-root ~/work      # добавить папку в список
python3 cockpit/aurora_cockpit.py --roots ~/work ~/tmp   # только эти папки, разово
```

## Что внутри

| Путь | Что это |
|---|---|
| `aurora_cockpit.py` | сервер: находит проекты, запускает команды из реестра, отдаёт JSON и поток вывода. Только стандартная библиотека |
| `ui/index.html`, `ui/panel.js`, `ui/panel.css` | ядро интерфейса: каркас страницы (`index.html`), меню, маршрутизация, консоль, запуск команд и редактор (`panel.js`), оформление ядра (`panel.css`) |
| `modules/<id>/` | разделы-папки: манифест, разметка, скрипт, свои строки. Появляются в меню сами — [modules/README.md](modules/README.md) |
| `i18n/ru.json`, `i18n/en.json` | строки ядра. Новый язык — новый файл; полнота проверяется `kit:i18n --check` |
| `i18n/data/<язык>.json` | перевод того, что отдаёт сервер: команды и флаги, маршруты, скины, коннекторы, сообщения об ошибках. Страница просит язык (`?lang=`) |
| `skins/*.css` | оформление в три слоя токенов — [skins/README.md](skins/README.md). Свой файл появляется в списке сам. По умолчанию «Зин 2.0» |
| `vendor/` | шрифты, редактор markdown и библиотека графа — готовыми сборками, без сети — [vendor/README.md](vendor/README.md) |
| `scenarios.txt` | маршруты «Быстрого старта» и «Продуктивности»: шаги рутинной работы обычным текстом |

## Разделы

Меню делится на три группы и консоль.

- **Машина:** Мостик (плитки всех проектов), Настройка кита, Установка, Справка, О проекте.
- **Проект:** Настройки проекта, Здоровье, Быстрый старт, Продуктивность, Файлы, Спросить, Команды,
  Зеркала, Версия; в режиме «Разработка» ещё Граф и Отчёты.
- **Движок:** Разработка — QA самого движка (открывается семью нажатиями на «О проекте»).
- **Консоль:** вывод запусков, код возврата, история.

Тринадцать разделов-модулей лежат в `modules/` (about, ask, commands, dev, graph, health, install,
mirrors, quickstart, reference, reports, version, work); Мостик, настройки, файлы и консоль живут в ядре.

## Как это устроено безопасно

- Сервер слушает **только 127.0.0.1** и требует токен сессии, выданный при старте. Токен живёт в
  памяти процесса: перезапустили — адрес сменился.
- Выполнить можно **только команды из реестра `commands.txt`**; аргументы уходят списком, без
  оболочки; флаг, не объявленный командой, отклоняется.
- Проект выбирается из списка обнаруженных, произвольный путь не принимается.
- `--apply` панель сама не подставляет: сначала предпросмотр, потом подтверждение.
- Секретов панель не касается: про токены знает только «заполнено» или «пусто».

## Клавиатура

`⌘K` / `Ctrl+K` — палитра: команды, разделы, проекты. `Esc` — закрыть.
