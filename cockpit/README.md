# Aurora Cockpit

Локальная панель управления фреймворком: все проекты машины, здоровье баз, запуск команд,
установка недостающего, обновление движка и справка — в одном окне.

```bash
python3 aurora.py cockpit
```

Откроется браузер на `http://127.0.0.1:8787/?t=<токен>`. Другие корни для поиска проектов
и другой порт:

```bash
python3 cockpit/aurora_cockpit.py --port 9000 --roots ~/work ~/Documents/Cursor_git
```

## Что внутри

| Файл | Что это |
|---|---|
| `aurora_cockpit.py` | сервер: находит проекты, запускает команды, отдаёт JSON. Только стандартная библиотека |
| `ui/index.html` | вся панель: структура, инлайн JS, без CDN и сборки |
| `skins/*.css` | оформление: цвета, шрифты, радиусы. Свой файл появляется в списке сам — см. `skins/README.md` |
| `scenarios.txt` | сценарии «Быстрого старта»: последовательность шагов рутинной работы |
| `DESIGN_BRIEF.md` | бриф на облик и характер интерфейса |

Требования к функциям — `docs/control-panel-ui-requirements.md`.

## Разделы

- **Мостик** — плитки всех проектов на машине: версия движка, доля проверенного знания,
  блокеры `doctor`, ошибки линтера, ветка и незакоммиченное. Цвет ауры — тяжесть проблем.
- **Здоровье** — метрики базы из `stats --json`, `lint`, `doctor`, `audit`. Каждая плитка
  кликабельна и ведёт к команде, которая с этим работает.
- **Команды** — весь реестр (48 команд): исполнитель, модификаторы, версия появления.
  Запускаются только команды-скрипты; у команд-процедур открывается описание.
- **Зеркала** — состояние Confluence и Jira, наличие токенов, цепочка синк → аудит → дрейф.
- **Установка** — чего не хватает на машине и в проекте, с указанием, какие команды
  без этого не работают.
- **Версия** — движок проекта против kit, предпросмотр обновления, миграция.
- **Консоль** — потоковый вывод команд, код возврата, история запусков.
- **Быстрый старт** — рутина по сценариям: утренний обход, пополнение базы, верификация,
  прополка, трассировка, передача наружу. Шаги идут сверху вниз, у каждого кнопка запуска;
  шаги, которые делает человек или ассистент, помечены и не запускаются.
- **Справка** — документация фреймворка с оглавлением.
- **О проекте** — версия, репозиторий, автор, лицензия, последние выпуски и **обновление
  самого kit из репозитория кнопкой** (только перемотка вперёд, при незакоммиченных
  правках отказывает).

## Как это устроено безопасно

- Сервер слушает **только 127.0.0.1** и требует токен сессии, выданный при старте.
  Токен живёт в памяти процесса: перезапустили — адрес сменился.
- Выполнить можно **только команды из реестра `commands.txt`**, аргументы уходят списком,
  без оболочки. Флаг, не объявленный командой, отклоняется.
- Проект выбирается из списка обнаруженных, произвольный путь не принимается.
- `--apply` панель сама не подставляет: сначала предпросмотр, потом подтверждение человеком.
- Секретов панель не касается: про токены синка знает только «заполнено» или «пусто».

## Клавиатура

`⌘K` / `Ctrl+K` — палитра: команды, разделы, проекты. `Esc` — закрыть.
