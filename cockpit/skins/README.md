# Скины панели

Оформление вынесено из разметки: панель задаёт структуру, скин — цвета, шрифты, радиусы.
Файл `*.css` в этой папке появляется в списке скинов сам, править сервер или интерфейс
для этого не нужно.

## Как сделать свой

Скопируйте `vault.css`, поменяйте значения и положите рядом под своим именем:

```css
/* name: Моя тема
   about: Одна строка о том, для чего этот скин. */

:root{
  --bg:#101014; --surface-1:#17171D; --surface-2:#1F1F27; --border:#33333F;
  --text:#EDEDF2; --text-muted:#9A9AA8;
  --primary:#7CE0A0; --accent:#E07CC6; --gold:#E0C97C;
  ...
}
:root[data-theme="light"]{ ... }
```

Имя в списке и подсказку панель берёт из шапки файла: `name:` и `about:`. Выбранный скин
запоминается в браузере. По умолчанию включён «Зин».

Скин подключается **последним**, после разметки, поэтому он может не только задать токены,
но и переопределить сам приём: тень, толщину рамки, фон полотна, регистр заголовков.
Пример — `zine.css`: там бумага в точку вместо пятен света и жёсткая тень вместо свечения.
Границу лучше не переходить: всё, что двигает элементы и меняет раскладку, — это правка
панели, а не скин.

## Токены

| Токен | Что красит |
|---|---|
| `--bg`, `--surface-1`, `--surface-2`, `--border` | фон, карточки, приподнятые элементы, линии |
| `--text`, `--text-muted` | основной и вторичный текст |
| `--primary` | первичное действие и состояние «здорово» |
| `--accent` | акцент, присутствие Авроры |
| `--gold` | необратимые действия и несохранённые правки |
| `--tier-imported`, `--tier-draft`, `--tier-inreview`, `--tier-verified`, `--tier-deprecated` | статусы карточек: тот же код, что и в самой базе |
| `--danger`, `--corruption` | ошибки и дрейф |
| `--glow`, `--radius`, `--mono`, `--sans` | свечение, скругления, шрифты |
| `--aura-1`, `--aura-2` | два пятна света на фоне; `transparent` — выключить |
| `--console-bg`, `--console-ink` | терминальные блоки: консоль, блоки кода, редактор конфига |

Тема (светлая или тёмная) переключается отдельной кнопкой и работает поверх скина:
описывайте оба варианта — `:root` и `:root[data-theme="light"]` (или `dark`, если ваш
скин светлый по умолчанию).

## Правила, которые лучше не нарушать

Статусы карточек должны оставаться различимыми: `verified` и `imported` — это разница
между фактом и слухом, и она читается по цвету во всех списках. Контраст текста —
не ниже WCAG AA, панель рассчитана на долгую работу. Свечение и анимации отключаются
системной настройкой `prefers-reduced-motion`, это уже учтено в разметке.
