# Скины панели

Оформление вынесено из разметки: панель задаёт структуру, скин — значения. Файл `*.css`
в этой папке появляется в списке скинов сам, править сервер или интерфейс для этого не нужно.

Главное правило: **скин не трогает селекторы разметки**. Всё, что раньше делалось
переопределением правил (`.btn{…}`, `.card{…}`, `body::before{…}`), теперь делается
токенами. Пока скины правили селекторы, любая правка вёрстки молча ломала оформление, и
узнать об этом можно было только глазами.

## Три слоя токенов

| Слой | Где живёт | Что в нём |
|---|---|---|
| 1. Палитра | скин | значения цветов и шрифтов этого оформления |
| 2. Смысл | разметка, скин перекрывает | `--bg`, `--text`, `--tier-*`, шкала кеглей, шаг сетки, радиусы, тени, длительности |
| 3. Компонент | разметка, скин перекрывает точечно | `--btn-*`, `--card-*`, `--chip-*`, `--nav-*`, `--tile-*`, `--h1-*` |

Компонент читает **только третий слой**. Поэтому скин, который хочет поменять цвет,
правит второй слой; скин, который хочет поменять приём — жёсткую тень вместо свечения,
сердце вместо ромба, капс у заголовка, — правит третий. Ни в том, ни в другом случае
селекторы панели не упоминаются.

## Как сделать свой

Скопируйте `pribory.css` (самый короткий), поменяйте значения и положите рядом под своим
именем. Имя в списке, подсказку и версию ядра панель берёт из шапки файла:

```css
/* name: Моя тема
   for: 1.120.0
   about: Одна строка о том, для чего этот скин. */

:root{
  --bg:#101014; --surface-1:#17171D; --surface-2:#1F1F27; --border:#33333F;
  --text:#EDEDF2; --text-muted:#9A9AA8;
  --primary:#7CE0A0; --accent:#E07CC6; --gold:#E0C97C;
  --sans:'Onest',system-ui,sans-serif;
  --card-radius:10px; --btn-weight:600;     /* приёмы — третий слой */
}
:root[data-theme="light"]{ /* тот же набор имён в светлых значениях */ }
```

Тема переключается кнопкой и работает поверх скина: **описывайте оба состояния**.
Атрибут `data-theme` на странице всегда есть — `dark` или `light`, — поэтому вариант
«по умолчанию» без второго блока даст половину панели в чужих цветах. Пока человек не
выбрал тему сам, панель берёт системную (`prefers-color-scheme`).

Шрифты лежат в ките (`cockpit/vendor/fonts`) и отдаются локально — Onest, Golos Text,
Unbounded, Literata, Nunito, Comfortaa, JetBrains Mono, IBM Plex Mono, лицензия OFL.
Наружу панель не ходит ни за чем; свой шрифт добавляется в ту же папку и объявляется в
`fonts.css` рядом.

## Токены

### Слой 2 — смысл

| Токен | Что задаёт |
|---|---|
| `--bg`, `--surface-1`, `--surface-2`, `--border`, `--border-strong` | фон, карточки, приподнятое, линии |
| `--text`, `--text-muted` | основной и вторичный текст |
| `--primary` | первичное действие и состояние «здорово» |
| `--accent` | акцент, присутствие Авроры |
| `--gold` | необратимые действия и несохранённые правки |
| `--tier-imported`, `--tier-draft`, `--tier-inreview`, `--tier-verified`, `--tier-deprecated` | статусы карточек: тот же код, что и в самой базе |
| `--danger`, `--corruption` | ошибки и дрейф зеркал |
| `--sans`, `--mono`, `--display` | текст, числа и код, заголовки |
| `--text-xs … --text-2xl` | шкала кеглей: шесть ступеней на всю панель |
| `--sp-1 … --sp-6` | шаг сетки, отступы кратны четырём |
| `--radius`, `--radius-sm`, `--radius-xs`, `--radius-pill` | скругления |
| `--glow`, `--shadow-card`, `--shadow-pop`, `--shadow-toast` | свечение и тени |
| `--motion-fast`, `--motion-slow` | длительности переходов |
| `--canvas-texture`, `--canvas-texture-size`, `--aura-1`, `--aura-2` | фактура полотна: пятна света, бумага в точку или ничего |
| `--console-bg`, `--console-ink` | терминальные блоки: консоль, код, редактор конфига |

### Слой 3 — приёмы компонентов

| Токен | Что меняет |
|---|---|
| `--card-bg`, `--card-border`, `--card-border-w`, `--card-radius`, `--card-shadow` | карточка: толщина рамки и тип тени |
| `--btn-bg`, `--btn-border`, `--btn-ink`, `--btn-radius`, `--btn-pad`, `--btn-weight`, `--btn-shadow`, `--btn-transform`, `--btn-ls`, `--btn-hover-border`, `--btn-hover-shift` | кнопка, включая регистр и «вдавливание» при наведении |
| `--btn-primary-bg`, `--btn-primary-border`, `--btn-primary-ink` | первичное действие |
| `--chip-bg`, `--chip-border-w`, `--chip-radius`, `--chip-weight`, `--chip-ink` | чип статуса |
| `--dot-size`, `--dot-radius`, `--dot-rotate`, `--dot-clip`, `--dot-ring` | форма точки статуса: ромб, квадрат, сердце |
| `--nav-bg`, `--nav-item-radius`, `--nav-item-active-bg`, `--nav-item-active-ink`, `--nav-marker-w`, `--nav-marker`, `--nav-marker-glow` | меню и отметка текущего раздела |
| `--header-bg`, `--header-blur` | шапка |
| `--tile-rail-w`, `--tile-aura-opacity`, `--tile-lift` | плитка проекта: полоса тяжести, пятно ауры, подъём под курсором |
| `--h1-font`, `--h1-size`, `--h1-weight`, `--h1-transform`, `--h1-ls`, `--h1-ink`, `--h1-shadow` | заголовок раздела |
| `--h2-transform`, `--h2-weight`, `--h2-ls`, `--eyebrow-ls` | подзаголовки и надписи-ярлыки |
| `--num-font` | начертание чисел: моноширинное или своё |
| `--field-bg`, `--field-border`, `--console-radius` | поля ввода и терминальные блоки |

## Правила, которые лучше не нарушать

Статусы карточек должны оставаться различимыми: `verified` и `imported` — это разница
между фактом и слухом, и она читается по цвету во всех списках. Контраст текста —
не ниже WCAG AA в обеих темах, панель рассчитана на долгую работу. Цвет никогда не
единственный признак статуса: рядом всегда есть подпись или форма. Свечение и анимации
отключаются системной настройкой `prefers-reduced-motion`, это уже учтено в разметке.

Если приёма не хватает и руки тянутся написать селектор — это не скин, а правка панели:
нужного токена просто ещё нет, и завести его правильнее, чем обойти.
