### 1.209.1 — manifest cards по id и классификация diagnostics

**Проблема:** `cards` в `manifest.json` сейчас объединяются по каноническому JSON; одна карточка с разными метаданными может дублироваться. `build_failures.json`, `unsupported.*`, `trace/*` не классифицированы.

**Содержание:**
- `merge_manifest.py`: cards по `id`/`name`, при совпадении — более новый `updated`/`processed`; без id — union.
- Классификация `build_failures.json`, `unsupported.*`, `trace/*`: SHARED/LOCAL/UNSURE с доказательствами в `docs/git-collaboration.md`.
- Для подтверждённых SHARED — merge-драйвер или отдельная часть; для UNSURE — оставить и записать причину.
- `tests/cases/part_199.py`: cards по id, diagnostics classification, отсутствие потери данных.
- `docs/git-collaboration.md` RU/EN.

**Проверяемые критерии:**
- Одна карточка с разными метаданными не дублируется.
- Классификация diagnostics имеет доказательства и тест.
- Полный гейт зелёный, тег `v1.209.1`.

**Результат 1.209.1:** коммит `43d050c2`, тег `v1.209.1`, ветка `rel/code-1.209.1`; полный гейт 2458/2458, 0 падений.
