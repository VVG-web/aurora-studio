# Быстрый старт

[Wiki](README.md) · дальше: [Цикл](The-Cycle.md)

## Что нужно

- **Python 3.9+** и **git**. У самого движка нет внешних зависимостей (только стандартная библиотека).
- По желанию: `pandoc` (выгрузка в docx/pdf), `beautifulsoup4` + `markdownify` (синк Confluence), `markitdown`, `openpyxl`,
  `pypdf` (офисные документы). Раздел панели **Установка** показывает, чего не хватает и какие команды от этого зависят.
- По желанию: OpenAI-совместимый шлюз LLM для встроенного агента. Всё, что не требует модели, работает без него.

## Установка тремя командами

```bash
git clone https://github.com/<org>/aurora-studio.git
cd aurora-studio
python3 aurora.py new /путь/к/вашему-проекту     # развернуть в новую или существующую папку; ответить на вопросы
python3 aurora.py cockpit                        # открыть локальную панель управления
```

Нет терминала? Дважды щёлкните `start-aurora.command` (macOS) или `start-aurora.bat` (Windows): он проверит Python и git,
предложит поставить недостающее и откроет панель. Без терминала вопросы настройки пропускаются, проект разворачивается со
значениями по умолчанию — доделайте настройку позже: `python3 aurora.py setup <проект>` или в панели.

## Что вы получаете

Папку проекта с **фиксированной раскладкой** (одинаковой во всех проектах Авроры): `Sources/` (зеркала, пишутся только
синком), `Raw/` (неизменяемые доказательства), `AuroraKnowledgeDB/` (карточки), `Artifacts/`, `Deliverables/`,
`Workspaces/` и `.opencode/` с копией движка. Подробности: [INSTALL](../../docs/INSTALL.md).

## Первые пятнадцать минут

1. **Проверьте готовность.** В панели `kit:doctor` (или `python3 aurora.py doctor <проект>`): он называет, чего не хватает —
   репозитория git, конфига, `AGENTS.md`, секрета, которому не место в git.
2. **Заполните настройки.** `aurora.config.yaml` хранит адреса, пространства, ключи проектов и JQL (он в git); токены — в
   `.env.aurora.local` (он вне git). Образец — `aurora.env.local.example`. См. [INSTALL, разделы 3–4](../../docs/INSTALL.md).
3. **Откройте проект в панели и нажмите «Обновить базу».** Она синхронизирует зеркала, собирает карточки партиями, пишет
   тезисы, связывает карточки, считает доверие и фиксирует каждый оборот в git. Останавливать можно в любой момент:
   сделанное остаётся годным. → [Цикл](The-Cycle.md)
4. **Загляните в «Здоровье».** Доля `knowledge`, ошибки линтера, что осталось человеку (`ops:todo`).
5. **Спросите что-нибудь.** Раздел **Спросить** отвечает только по карточкам и ставит ссылку на каждое утверждение. →
   [Спросить базу](Asking-the-Base.md)
