# Windows и macOS

[Wiki](README.md) · см. также: [Если что-то не так](Troubleshooting.md) · [Карточка](The-Card.md#что-стоит-помнить)

Кит разрабатывается на Linux и проверяется на каждый push на **Linux (Python 3.12 и самой старой поддерживаемой 3.9) и
Windows (`windows-latest`)**. Проект одновременно открывают люди на Windows, macOS и Linux, поэтому правило для имён —
самое строгое из трёх.

## Имена файлов должны проходить везде

| Правило | Почему |
|---|---|
| без `< > : " / \ \| ? *` | Windows их не принимает |
| не `CON`, `NUL`, `COM1`, … | зарезервированы в Windows |
| не больше **255 байт** на имя (кириллица — два байта на букву) | пределы macOS и Linux |
| путь от корня проекта до **200 символов** | предел Windows в 260 с запасом |
| имена в одной папке различаются не только регистром | macOS и Windows считают `A` и `a` одним файлом |
| буквы в NFC | macOS создаёт имена в NFD; то же слово тогда выглядит для Linux иначе |
| без точки или пробела в конце | Windows их отрезает |

Проверяет `kit:doctor`, чинит `kb:names` (предпросмотр, затем `--apply`). Пути зеркал синхронизация сокращает сама, когда
глубокая ветка Confluence не помещается.

## Windows

- **Запуск:** двойной щелчок по `start-aurora.bat`. Он ищет Python, предлагает поставить недостающее и открывает панель.
- **Python:** запускатели пробуют `python` и `py`, прежде чем доверять заглушке; нужны Python 3.9+ и git.
- **Открытый файл нельзя заменить.** Windows не даёт заменить файл, который читает другой процесс. Атомарные записи движка
  (манифест, векторный индекс, настройки) ждут и повторяют попытку, а не падают.
- **pid чужого процесса.** Блокировка пишущего прогона спрашивает у системы через Windows API, жив ли владелец, и никогда не
  шлёт ему сигнал («сигнал 0» в Windows остановил бы процесс).
- **Кодировка.** Консоль и каналы в cp1251/cp1252; движок переключает свой вывод и вывод дочерних процессов на UTF-8, поэтому
  русский текст и `—` не теряются.
- **Пути** в собственных отчётах движка и в панели везде с `/`, какая бы ни была система.
- **Символьные ссылки** требуют привилегии. Установщик скиллов копирует скиллы в `~/.claude/skills` и, если не смог создать
  ссылку для другого harness, говорит об этом и продолжает.
- **Концы строк.** Выгрузка git с `autocrlf` превращает файлы кита в CRLF; движок читает их как текст, так что это безвредно.
- **Разные диски.** Проект на `D:` при оболочке на `C:` работает: движок не предполагает один диск.

## macOS

- **`start-aurora.command` блокируется** Gatekeeper в первый раз: правая кнопка → *Открыть*.
- **Системный Python — 3.9**, это нижняя поддерживаемая версия. Запускатель распознаёт заглушку «Xcode command line tools» как
  «не Python» и говорит, что поставить.
- **Файловая система без учёта регистра.** Переименование `raw` → `Raw` делается в два шага: `mv raw tmp && mv tmp Raw`.
- **Имена NFD.** macOS хранит имена с диакритикой и кириллицей в разложенном виде; `kit:doctor` их находит, а `kb:names`
  нормализует.

## Что гарантируют тесты

Тот же набор идёт на Windows в CI тремя параллельными частями. Он покрывает блокировки, атомарные записи, пути с `\`, каналы в
UTF-8, файлы с кириллическими именами под `.gitignore`, терминал, который на деле `NUL`, и проекты на другом диске.
Проблема на Windows, которой нет в этом списке, — ошибка; заведите, пожалуйста, issue.
