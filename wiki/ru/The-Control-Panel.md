# Панель управления

[Wiki](README.md) · см. также: [Быстрый старт](Getting-Started.md) · [Повседневная работа](Daily-Work.md) · полный текст:
[панель управления](../../docs/control-panel-ui-requirements.md)

Локальная веб-страница, которая работает только на вашей машине (`127.0.0.1`) и управляет движком: находит проекты, запускает
команды реестра и показывает их вывод по ходу. Это не сервер для команды — каждый аналитик поднимает свою.

```bash
python3 aurora.py cockpit                              # или двойной щелчок по start-aurora.command / .bat
python3 cockpit/aurora_cockpit.py --port 9000          # другой порт
python3 cockpit/aurora_cockpit.py --add-root ~/work    # добавить папку, где искать проекты
```

`⌘K` / `Ctrl+K` открывает палитру: команды, разделы, проекты. Язык (русский или английский), тема и оформление
переключаются в шапке.

## Разделы

| Группа | Раздел | Зачем |
|---|---|---|
| **Машина** | Мостик | плитки всех проектов: версия движка, доля `knowledge`, блокеры, ошибки линтера, ветка, незакоммиченное. Цвет ауры — серьёзность: бирюзовый — порядок, янтарный — стоит взглянуть, красный — блокеры |
| | Настройка кита | где панель ищет проекты; подключение нового проекта; весь конфиг текстом |
| | Установка | чего не хватает на машине и какие команды от этого зависят; дополнения движка |
| | Справка | документация с оглавлением |
| | О проекте | версия, репозиторий, релизы и **обновление кита кнопкой** |
| **Проект** | Настройки проекта | доступы (токены: «заполнено / пусто»), конфиг, виды артефактов, шлюзы и роли агента, серверы MCP |
| | Здоровье | состав базы, доверие, связи, ошибки, свежесть зеркал, что осталось человеку; каждая плитка ведёт к команде, которая это чинит |
| | Рутины | маршруты базы: **Обновить**, **Починить**, **Пересобрать** — с «Предпросмотром», который ничего не пишет |
| | Производство | **Написать артефакт** и **Сдать документы** |
| | Файлы | дерево проекта, редактор Markdown (таблицы, mermaid, формулы), «Закоммитить» и «Отправить» |
| | Спросить | вопросы к базе; разговоры хранятся для всех |
| | Команды | весь реестр: исполнитель, модификаторы, версия, последний запуск |
| | Зеркала | состояние Confluence, Jira и сайтов; цепочка синхронизация → аудит → расхождения |
| | Версия | движок проекта против кита; предпросмотр обновления |
| **Консоль** | Консоль | потоковый вывод запусков, код возврата, история; запуск маршрута раскрывается по шагам |

## Принципы, которые стоит знать

- **Ничего не пишется без предпросмотра.** Панель сама не добавляет `--apply`: сначала предпросмотр, затем ваше подтверждение.
- **Запуск переживает закрытую вкладку.** Задачи живут в процессе панели; перезагрузка страницы не прячет работающую задачу.
  Повторный запуск той же команды в том же проекте возвращает уже идущую задачу, а не вторую.
- **Остановленный маршрут продолжается** с того места, где встал, а карточка на Мостике говорит, что идёт и что остановилось.
- **Секреты не возвращаются.** Введённый токен записывается в `.env.aurora.local`; панель показывает только
  «заполнено / пусто».
- **Ничего не выходит за loopback.** Страница и её токен отдаются только на `127.0.0.1`, чужой `Host` панель отклоняет.
- **Интерфейс переведён** (русский, английский). Что движок печатает в консоль — отчёты, вывод линтера — остаётся
  русским; собственные тексты панели, описания команд и флагов, маршруты и сообщения об ошибках следуют языку.

## Внешний вид

У панели есть оформления (`cockpit/skins/*.css`, три слоя токенов): Zine 2.0 (по умолчанию), Contrast, Gauges, Editorial,
Unicorn. Оформление меняет вид, а не смысл: плотность и шкала доверия те же. См.
[оформления](../../cockpit/skins/README.md).
