# Словарь

[Wiki](README.md) · см. также: [Карточка](The-Card.md) · [Доверие](Trust.md)

| Термин | Значение |
|---|---|
| **Aurora Studio / кит** | Этот репозиторий: движок, скиллы, шаблоны и панель. Разворачивается в проект, который дальше несёт собственную копию |
| **Проект** | Папка с `aurora.config.yaml` и фиксированной раскладкой. Хранит свою копию движка в `.aurora/` и своё знание |
| **Карточка** | Markdown-файл со знанием об одной сущности. [Карточка](The-Card.md) |
| **Вид** (`kind`) | `dictionary`, `document` или `knowledge` — решает, кто может править тело |
| **Статус** | `knowledge`, `draft`, `placeholder`, `index`, `deprecated` — класс доверия |
| **Доверие** | Вычисляется по статусам Jira и месту источника; не назначается. [Доверие](Trust.md) |
| **`trust_basis`** | Основание статуса карточки словами («PRJ-123 в работе») |
| **Тезис** | Короткое утверждение, которое пишет модель над дословным источником карточки `knowledge` |
| **Момус** | Вторая модель, которая сверяет каждое утверждение с источником |
| **Заготовка / placeholder** | Карточка, созданная только потому, что ссылка называет понятие; исключена из поиска и контекста, пока не появится определение |
| **Зеркало** | Детерминированная копия Confluence, Jira или сайта в `Sources/` |
| **`Raw/`** | Неизменяемые свидетельства: договор, законы, материалы заказчика, встречи, поправки |
| **Поправка** | Заметка человека о том, что карточка неверна; лежит в `Raw/corrections/` и применяется при каждой сборке (`kb:correct`) |
| **Артефакт** | Произведённый документ в `Artifacts/`; никогда не знание |
| **`based_on`** | Карточки, на которых стоит артефакт |
| **Поставка** | Артефакт, собранный для передачи; в `released/` — замороженные снимки |
| **DR (Decision Record)** | Дописываемая запись о решении с отклонёнными вариантами |
| **REQ, SPEC, Q** | Карточки требования, спецификации и вопроса заказчику (`REQ-NNN`, `SPEC-NNN`, `Q-NNN`) |
| **MOC** | Карта содержания — генерируемая индексная карточка, делающая карточки достижимыми |
| **Маршрут** | Упорядоченный набор шагов, запускаемый одной кнопкой: Обновить, Починить, Пересобрать, Написать, Сдать |
| **Круг** (loop) | Одна порция: разобрана, получила тезисы, связана и закоммичена — прогон нарезан на целые круги |
| **Кольцо** | Пронумерованный список шлюзов LLM, через которые идёт вызов |
| **Шлюз / backend** | Совместимая с OpenAI точка доступа к LLM |
| **Храповик** | Правило pre-commit: число ошибок линтера расти не может |
| **git-guard** | Отказ писать по грязному дереву, чтобы откат оставался возможным |
| **Скилл** | Процедура для ассистентов: `aurora-vault`, `aurora-grill`, `aurora-dev` |
| **MCP** | Model Context Protocol; сервер Авроры даёт ассистенту базу как инструмент только для чтения |
| **Cockpit / панель** | Локальная веб-панель управления |
| **Манифест движка** | `engine_manifest.txt`: белый список файлов, которые `update` может перезаписать в проекте |
| **Реестр** | `commands.txt`: единственный источник истины о том, какие команды есть |
